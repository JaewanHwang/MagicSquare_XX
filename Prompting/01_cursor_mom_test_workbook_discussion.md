### 페르소나
4×4 부분 마방진(빈칸 2개)을 과제로 푸는 학습자. 커서 과제 환경에서 1~16 숫자를 배치하고, 합이 34인지를 **손으로** 검산함.

### 인터뷰 답변 (과거 사실)

- 대각선 하나를 빼먹어서, **다 맞은 줄 알고 넘어갔다가 나중에 틀린 걸 발견**했다.
- 그 일로 **20분을 날렸다**.
- 줄 하나를 빠뜨리고 넘어간 건 **이번이 처음이 아니다(전에도 있었다)** → 반복 패턴.

### 표면 문제 (금지 — 솔루션 섞인 문장)
> ⚠️ 아래는 "이렇게 말하기 쉽지만 진짜 문제가 아닌" 솔루션 섞인 문장 예시야. 이렇게 정의하면 안 됨.
- "합을 자동으로 계산해주는 코드가 있으면 좋겠다"
- "검산 버튼을 만들면 된다"
- "대각선도 체크하는 함수를 추가하자"

→ 전부 **해결책**이라 표면 문제임. 인터뷰에서 너는 이렇게 말한 적 없음(= 좋은 신호).

## MagicSquare_1004 — 세션 3 워크북

**페르소나:** 4×4 격자, 빈칸 2개(0), 1~16, 합 34를 맞추는 학습자
**진짜 문제(확정):** 손 검산 시 10개 줄(4행·4열·2대각선) 중 하나를 빠뜨려도 즉시 판정되지 않아, 다 맞은 줄 알고 넘어갔다가 뒤늦게 오답을 발견해 시간을 날린다.

### 1) 주제 한 문장 (Mom Test 기반)
**"완성된 4×4 격자가 진짜 마방진인지 — 10개 줄 전부 합이 34인지 — 빠짐없이 즉시 판정한다."**
*(솔루션이 아니라 "빠짐없는 즉시 판정"이라는 불편 해소에 초점)*

### 2) R-G-I-O
| 항목 | 내용 |
| --- | --- |
| **Role** | 마방진 검증기(SquareValidator) |
| **Goal** | 10개 줄(4행+4열+2대각선)을 하나도 빠뜨리지 않고 합=34 여부를 판정 |
| **Input** | 4×4 정수 격자 (1~16, 빈칸은 0) |
| **Output** | `유효/무효` + 무효일 때 **틀린 줄의 위치 목록** |

### 3) 성공 기준 3개 (Mom Test 증거 연결)
1. **완전성** — 10개 줄을 100% 검사한다(누락 0). ← *"대각선 하나를 빼먹어서 20분 날렸다"*
2. **즉시 판정** — 격자를 넣으면 손 검산 없이 즉시 유효/무효가 나온다. ← *"나중에 대각선 하나가 틀린 걸 발견했어"*
3. **재현 방지** — 같은 격자를 다시 넣어도 항상 같은 판정이 나온다(반복 누락 차단). ← *"전에도 있었어"*

### 4) 표면 문제 — 이번 프로젝트에서 **하지 않을 것**
- 빈칸을 **자동으로 채우는 풀이 알고리즘**(Solver) → 이번 세션 범위 밖
- GUI 격자 시각화/버튼 → 범위 밖
- 1~16 중복·범위 입력 검증 같은 부가 검사 → 이번엔 **합 판정만**

## 8계층 중 이번 세션 산출물만

### Rule
- 마방진 상수: `MAGIC_SUM = 34`, 격자 `4×4`
- 검사 대상 = **정확히 10줄**: 4행 + 4열 + 주대각선 + 반대각선
- 빈칸(0)이 하나라도 있으면 → `무효(미완성)`
- 한 줄이라도 합 ≠ 34 → `무효`, 해당 줄 위치를 반환

### Command
```
validate(grid: int[4][4]) -> { valid: bool, failedLines: Line[] }
```
- 입력: 4×4 격자
- 출력: 유효 여부 + 틀린 줄 목록(예: `["row0", "col2", "diag_main"]`)

### (Skill)
- `sumLine(cells)` : 한 줄의 합 계산
- `collectLines(grid)` : 격자 → 10줄 목록으로 변환(이 함수가 "누락 0"의 핵심)

### Test Loop
| # | 입력 | 기대 | 검증하는 성공기준 |
| --- | --- | --- | --- |
| T1 | 정답 마방진 | `valid=true` | 즉시 판정 |
| T2 | 대각선 1줄만 틀린 격자 | `valid=false`, `failedLines=[대각선]` | **완전성**(대각선 누락 방지) |
| T3 | 빈칸(0) 포함 격자 | `valid=false`(미완성) | 즉시 판정 |
| T4 | 같은 격자 2회 입력 | 두 번 다 동일 결과 | 재현 방지 |
| T5 | 행은 다 맞고 열 1개 틀림 | `failedLines=[col*]` | 완전성(열 누락 방지) |

→ **T2가 이 프로젝트의 심장**: "대각선 빼먹는" 바로 그 실패를 테스트가 대신 잡아줌.
