# MagicSquare_1004 — PRD (제품 요구사항 정의서)

## 0. 배경 — 진짜 문제
손 검산 시 10개 줄(4행·4열·2대각선) 중 하나를 빠뜨려도 즉시 판정되지 않아, 다 맞은 줄 알고 넘어갔다가 뒤늦게 오답을 발견해 시간을 날린다.

## 1. 주제 한 문장
**완성된 4×4 격자가 진짜 마방진인지 — 10개 줄 전부 합이 34인지 — 빠짐없이 즉시 판정한다.**

## 2. R-G-I-O
| 항목 | 내용 |
| --- | --- |
| **Role** | 마방진 검증기 (SquareValidator) |
| **Goal** | 10개 줄(4행+4열+2대각선)을 하나도 빠뜨리지 않고 합=34 여부 판정 |
| **Input** | 4×4 정수 격자 (1~16, 빈칸은 0) |
| **Output** | `유효/무효` + 무효 시 **틀린 줄의 위치 목록** |

## 3. 성공 기준 (Mom Test 증거 연결)
1. **완전성** — 10개 줄을 100% 검사(누락 0). ← "대각선 빼먹어서 20분 날렸다"
2. **즉시 판정** — 격자 입력 시 손 검산 없이 즉시 유효/무효. ← "나중에 틀린 걸 발견했어"
3. **재현 방지** — 같은 격자는 항상 같은 판정. ← "전에도 있었어"

## 4. 범위 밖 (이번 프로젝트에서 하지 않을 것)
- 빈칸 자동 풀이 알고리즘(Solver)
- GUI 격자 시각화 / 버튼
- 1~16 중복·범위 검증 (이번엔 **합 판정만**)

## 5. 사양 — 8계층 중 이번 세션 산출물

### 5.1 Rule
- 상수: `MAGIC_SUM = 34`, 격자 `4×4`
- 검사 대상 = 정확히 **10줄**: 4행 + 4열 + 주대각선 + 반대각선
- 빈칸(0) 하나라도 있으면 → `무효(미완성)`
- 한 줄이라도 합 ≠ 34 → `무효` + 해당 줄 위치 반환

### 5.2 Command
```
validate(grid: int[4][4]) -> { valid: bool, failedLines: Line[] }
```
- 입력: 4×4 격자
- 출력: 유효 여부 + 틀린 줄 목록 (예: `["row0", "col2", "diag_main"]`)

### 5.3 Skill (보조 함수)
- `sumLine(cells)` : 한 줄의 합 계산
- `collectLines(grid)` : 격자 → 10줄 목록 변환 ("누락 0"의 핵심)

### 5.4 Test Loop
| # | 입력 | 기대 | 검증 기준 |
| --- | --- | --- | --- |
| T1 | 정답 마방진 | `valid=true` | 즉시 판정 |
| T2 | 대각선 1줄만 틀린 격자 | `valid=false`, `failedLines=[대각선]` | **완전성** |
| T3 | 빈칸(0) 포함 격자 | `valid=false`(미완성) | 즉시 판정 |
| T4 | 같은 격자 2회 입력 | 두 번 다 동일 결과 | 재현 방지 |
| T5 | 행 정상, 열 1개 틀림 | `failedLines=[col*]` | 완전성 |

> **T2가 핵심**: "대각선 빼먹는" 실패를 테스트가 대신 잡는다.
